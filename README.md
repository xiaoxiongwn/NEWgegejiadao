# 👑 格格驾到

局域网文件直传 / 直接编辑 工具。不依赖 Windows 自带的"文件共享"功能（公司电脑即使禁用了共享也能用），
纯 Python 标准库实现核心协议（WebDAV），打包后是**绿色免安装**的单个 `.exe`。

## 功能

- **电脑互传互编**：基于 WebDAV，对方电脑可以直接在"文件资源管理器"里打开、编辑、保存你共享的 Word / Excel 等文件，不需要手动下载再上传。
- **手机访问**：内置一个简易网页，手机扫码即可浏览、下载、上传文件。
- **同事地址簿**：保存常联系的同事电脑地址，一键打开对方共享的文件夹。
- **密码可选**：共享时可以设置密码，也可以留空不设密码。
- **提醒功能**：点击"🔔提醒TA"，对方电脑的任务栏图标会闪烁 + 弹出提示，告诉对方"我给你发了文件"。
- **开机自启动**：可选，设置后开机就自动运行（在系统托盘后台运行）。
- **后台隐藏运行**：关闭窗口不会退出程序（不显示任何托盘图标），共享会继续在后台运行；想重新打开时，再双击一次 `格格驾到.exe`（或桌面快捷方式）即可自动唤出已有窗口，不会开出重复的新窗口。想真正退出，在"设置"页点击"彻底退出程序"。

## 如何打包成 exe（在 GitHub 上）

1. 在 GitHub 新建一个仓库（比如 `gegejiadao`），把这个项目的所有文件（包括 `.github` 文件夹）上传 / push 上去。
2. 打开仓库的 **Actions** 标签页，会自动触发"构建 格格驾到.exe"这个工作流（如果没有自动触发，点 **Run workflow** 手动触发一次）。
3. 等构建完成（一般 2-5 分钟），进入这次运行的详情页，下滑到 **Artifacts** 区域，下载 `格格驾到-windows-exe`，解压后就是 `格格驾到.exe`。
4. 把这个 exe 拷给同事，双击就能直接用，不需要安装 Python，也不需要联网。

## 本地开发/调试（可选，需要联网环境）

```bash
pip install -r requirements.txt
python app.py
```

```
└── .github/workflows/build.yml   # 自动打包流程
```

## 使用方法

1. 打开"我的共享"标签页，选择要共享的文件夹，可选填密码，点击"开始共享"。
2. 把界面上显示的电脑访问地址（`\\IP@端口\`）发给同事，对方在资源管理器地址栏粘贴即可直接打开、编辑、保存文件。
3. 或者用手机扫描界面右侧的二维码，直接在手机浏览器里浏览/上传/下载文件。
4. 在"同事地址簿"里添加同事的电脑信息，以后一键"打开"即可访问，也可以点"🔔提醒TA"通知对方。

## 注意事项

- 本工具面向**内部局域网**可信环境设计，不建议在公网或不受信任的网络中使用。
- 密码保护基于 HTTP Basic Auth，传输未加密，仅适合公司内网环境。
- 首次运行时 Windows 防火墙可能会弹窗询问是否允许联网，请选择"允许访问"（专用网络和公用网络都建议勾选）。
